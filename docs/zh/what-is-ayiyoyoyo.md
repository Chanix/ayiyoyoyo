# ayiyoyoyo 是什么？ {#what-is-ayiyoyoyo}

## 功能特点

- 使用操作系统内嵌的浏览器组件，占用资源少
- 支持远程服务器 / 本地服务器 / 无服务器多种运行模式
- 提供 JavaScript 可调用的扩展对象，可操作文件、系统、Python 等
- 支持主流操作系统和主流前端开发框架
- 可定制、可剪裁：按需增减内置的 JS 扩展模块

## 安全风险

ayiyoyoyo 使用系统内嵌的浏览器组件，同时提供了操作本地资源的功能扩展。因此，某些安全软件可能会报告存在病毒木马行为。这是软件功能和运行机制决定的，并非病毒木马。

ayiyoyoyo 提供了运行环境，在其基础上运行的小应用由第三方提供。因此 ayiyoyoyo 没有能力保证小应用代码的功能和目的。如果执行了存在恶意代码的小应用，可能会造成安全隐患。

请只运行您信任的小应用。
