ayiyoyoyo 是跨平台桌面应用的快速开发工具。

用前端技术快速开发、调试，通过 JS 调用 API，用 Python 增强能力，打包成分发给用户。

绿色、轻量、即用即走。

**ayiyoyoyo 的目标：低成本解决 80% 的需求，省下更多时间用来陪伴、娱乐和成长。**

实现这个目标的工具架构有很多，但对于简单的小需求，往往有点杀鸡用牛刀的感觉。复用现有技术，降低心智压力，快速完成任务，然后放空躺平摸鱼——此吾所求也。

## 核心概念：基座 + 小应用

你可以把 ayiyoyoyo 理解成一个**基座**，上面运行**小应用**。

- **小应用**用 JS 开发，界面由 webview 承载。你可以用任何喜欢的方式或框架——Vue、React、原生 HTML 都行，只要能生成本地网站，就能被包装起来。
- **JS 可以调用基座提供的 API**，突破浏览器沙箱限制，操作本地资源：读写文件、调用系统功能、运行 Python 脚本等。
- **远程网站也能包装**，在此基础上叠加自己的扩展，比如自动化操作、快捷键增强。
- **小应用开发完成后**，打包成 zip 分发，或放到网络上供用户远程安装。只要有 ayiyoyoyo，用户就能很方便地使用。小应用的体积通常很小。

有点类似小程序、快应用的意思。

## 适用场景

- 一套代码，快速完成能在多种操作系统上运行的桌面应用；
- 将现有网址快速封装为跨平台的桌面应用；

## 功能特点

- 使用操作系统内嵌的浏览器组件，占用资源少
- 支持远程服务器 / 本地服务器 / 无服务器多种运行模式
- 提供 JavaScript 可调用的扩展对象
- 支持主流操作系统和主流前端开发框架
- 可定制、可剪裁
