# ayiyoyoyo 是什么？ {#what-is-ayiyoyoyo}

## 概览

可以把 ayiyoyoyo 理解成一个**基座**，上面运行**小应用**。

> 类比一下，有点类似微信和微信小程序。

- **小应用（Appchip）** 用前端技术开发，界面由 WebView 承载。您可以用任何喜欢的方式（Vue / React / 原生 HTML 均可），只要能生成网页，就能被包装起来。
- **远程网站** 也可以转化为桌面应用，并在其原基础上增加自定义的扩展，例如自动化操作、快捷键增强等等。
- **JavaScript 可以调用基座提供的 API**，突破沙箱限制，操作本地资源，增强能力。例如：读写文件、调用系统功能、运行 Python 脚本。
- **小应用开发完成后**，可以打包成 zip 分发，也可以放到网站上供用户从网址安装。用户只需安装一次 ayiyoyoyo，之后就能轻量地使用各类小应用。
- **一套小应用代码**，可运行于多个操作系统并保持一致性，轻松完成跨平台桌面应用。

## 功能特点

- 使用操作系统内嵌的浏览器组件，占用资源少；
- 支持远程服务器 / 本地服务器 / 无服务器多种运行模式；
- 提供 JavaScript 可调用的扩展对象，可操作文件、系统、Python 等；
- 支持主流操作系统和主流前端开发框架；
- 可定制、可剪裁：按需增减内置的 JS 扩展模块；

## 安全风险

ayiyoyoyo 使用系统内嵌的浏览器组件，同时提供了操作本地资源的功能扩展。因此，某些安全软件可能会报告存在病毒木马行为。这是软件功能和运行机制决定的，并非病毒木马。

ayiyoyoyo 提供了运行环境，在其基础上运行的小应用由第三方提供。因此 ayiyoyoyo 没有能力保证小应用代码的功能和目的。如果执行了存在恶意代码的小应用，可能会造成安全隐患。

请只运行您信任的小应用。
