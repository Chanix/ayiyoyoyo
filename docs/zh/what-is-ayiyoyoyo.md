# ayiyoyoyo 是什么？ {#what-is-ayiyoyoyo}

ayiyoyoyo 是一套利用 WebApp 技术，快速完成开发调试，并将应用分发为跨平台桌面应用的绿色工具，专为便捷实用而设计。

你可以这么理解，ayiyoyoyo 是一个基座，上面运行小应用。小应用用 js 来开发，用 webview 实现界面。可以用任何喜欢的方式或者架构，例如
vue/react 等，只要生成本地网站就可以包装起来，js可以调用基座提供的api，突破沙箱限制，操作本地资源，例如读写本地文件，调用系统功能。
只要是网站就可以，当然也可以包装远程网站，加上自己的扩展，例如自动化操作，增加快捷键什么的。
小应用开发完成以后，可以打包成zip分发，或者放在网络上供用户远程安装。只要用户有ayiyoyoyo就可以很方便的使用。小应用也很小。
有点类似小程序，快应用的意思吧。
大概是这样，可能说的不够清晰，后面再补充完善吧。

借助 ayiyoyoyo，您可以：

- 一套代码，快速完成能在多种操作系统上运行的桌面应用；
- 将现有网址快速封装为能在多种操作系统上运行的桌面应用；

实现这个目标的工具架构有很多，但对于简单的小需求，往往有点杀鸡用牛刀的感觉。复用现有技术，降低心智压力，快速完成任务，然后放空躺平摸鱼，此吾所求也。

ayiyoyoyo 的目标：低成本的解决 80% 的需求，省下更多的时间用来陪伴、娱乐和成长。


## 功能特点

- 使用操作系统内嵌的浏览器组件，占用资源少；
- 支持 远程服务器/本地服务器/无服务器 多种运行模式；
- 提供 JavaScript 可调用的扩展对象；
- 支持主流操作系统、支持主流前端开发框架；
- 可定制可剪裁；

## 安保风险

ayiyoyoyo 使用系统内嵌的浏览器组件，同时提供了操作本地资源的功能扩展。
因此某些安全软件有可能会报告存在病毒木马行为。这是软件功能和运行机制决定的，并非病毒木马。

ayiyoyoyo 提供了运行环境，在其基础上运行的小应用由第三方提供。
因此 ayiyoyoyo 没有能力保证小应用代码的功能和目的。
如果执行了存在恶意代码的小应用，有可能会造成安全隐患。
