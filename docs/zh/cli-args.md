# 命令行参数 {#cli-args}

ayiyoyoyo 支持通过命令行参数传递参数，控制行为。

## 参数一览

| 参数        | 说明                                   |
|:------------|:---------------------------------------|
| `--appchip` | 指定运行的小应用，默认为 `__default__` |
| `--help`    | 显示帮助信息                           |

## 参数详解

### --appchip

指定启动时运行的小应用。

```shell
ayiyoyoyo --appchip my_appchip
```

### --help

显示帮助信息。

```shell
ayiyoyoyo --help
```
