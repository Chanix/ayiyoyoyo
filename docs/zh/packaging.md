# 打包与分发 {#packaging}

小应用开发完成后，打包成 zip 分发给用户。

## 打包

用 DevKit 的「打包小应用」功能打包。

### 打包步骤

1. 打开 DevKit，选择「打包小应用」
2. 从下拉列表里选择要打包的小应用
3. 选择输出目录
4. 点「打包」

### 打包产物

产物是一个 zip 文件，文件名固定为 `<appchip-id>.zip`。

zip 内部的目录结构：

```
<appchip-id>.zip
└─ <appchip-id>/
   ├─ appchip.json
   ├─ appchip.ico
   ├─ js/
   └─ webroot/
```

打包时会**压缩小应用目录下的所有文件**，不做任何排除。请开发者自行保证目录干净，不要放入 `.git`、`node_modules`、临时文件等不需要分发的内容。

### 输出路径

输出目录由用户选择，最终文件为 `<输出目录>/<appchip-id>.zip`。如果同名文件已存在，会直接覆盖。

## 分发

有两种分发方式。

### 从文件分发

把 `<appchip-id>.zip` 直接发给用户。用户在「小应用管理器」里选择本地 zip 安装。

适合：

- 内部分享
- 通过邮件、IM 发送
- 放在网盘、共享目录

### 从网址分发

把 `<appchip-id>.zip` 放到服务器，用户填入 URL，基座自动下载并安装。

适合：

- 公开发布
- 希望用户拿到最新版

目前从网址安装**只做下载和安装，不做签名校验**。

## 安装流程

用户在「小应用管理器」里安装：

**从文件**：

1. 点「选择」按钮，选本地 zip
2. 点「安装」

**从网址**：

1. 在「从网址」输入框填入 zip URL
2. 点「安装」

安装完成后，小应用出现在「已安装」列表里。

## 覆盖安装

如果目标 appchip id 已存在，安装会**覆盖**旧版本的程序目录。

数据目录（`data/data/<id>/`）和 webview 数据目录（`data/wvdata/<id>/`）**保留不变**，这样用户的数据不会丢失。

**覆盖安装同时也是更新小应用的方式**——重新打包新版，让用户重新安装即可。目前没有自动更新机制。

## 卸载

在「小应用管理器」里删除小应用。有两种模式：

- **仅删程序**：保留数据目录，便于重新安装后继续使用
- **彻底删除**：连同数据目录、webview 数据目录一起删除
